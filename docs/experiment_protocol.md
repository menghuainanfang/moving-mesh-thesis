# 实验协议

## 每次运行记录

实验 ID、日期、项目提交或 dirty 说明、FEALPy 提交与 dirty 状态、解释器和依赖、后端/dtype、配置、随机种子、网格规模、求解容差、耗时、停止原因、原始指标和输出文件。

当前脚本无随机过程；随机种子记为“不适用”。计时是单次墙钟时间，只用于本机小规模基线，不作为性能结论。

## 指标与失败判据

| 实验 | 核心指标 | 判为失败 |
| --- | --- | --- |
| A 几何 | 有向面积、总面积、边界节点、手算 Jacobian | 翻转未呈负号；退化未呈 0；单位方形总有向面积不为 1 |
| B 等分布 | 逐段监控质量偏差、节点单调、插值 L2/L∞ 误差 | 节点不严格递增、端点移动、质量偏差超阈值或目标 L2 误差不优于均匀网格 |
| C Poisson | L2/H1 半范数误差、观测阶、边界误差、相对线性残差、耗时 | 边界或残差异常；P1 在光滑解和规则网格上未接近 L2 二阶/H1 一阶 |
| D MMesher | 最小有向面积、总面积、节点位移、插值误差、耗时、停止信息 | 任一单元非正定向、面积不守恒到数值容差、运行异常 |

D 的插值误差升降是观察量，不预设必须改善；极小网格和固定 3 步只验证当前代码路径。GFMMPDE 没有暴露离散网格能量历史，因此本轮不设能量阈值。

## 对照原则

- 比较方法时固定初始网格、节点数、目标函数和停止口径。
- 误差—成本报告包含网格移动、解转移与 PDE 求解总成本。
- 能量比较必须固定能量定义、归一化和度量状态；质量分数不能替代能量。
- 用有向面积检查方向；不以绝对面积掩盖翻转。
- 证据标签使用：已证明、原文定理、已复现实验、本轮观察、待验证猜想。

## 当前输出

JSON/CSV 是原始数值记录，PNG 只作展示。脚本和配置随仓库保存；`results/` 中生成物默认不纳入 Git，以避免把重复输出当源文件。
